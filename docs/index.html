  1. חפשו ספר מספריא בתיבת החיפוש למטה והוסיפו אותו.
  2. פתחו את הספר כדי להתחיל לכתוב פרשנות.
  3. אופציונלי: חברו את החשבון ל-Google בהגדרות כדי לייצא ל-Docs/Sheets.
    הוספת פרק ספציפי מתוך ספר

    בחרו ספר ופרק - הדפדוף (הבא/הקודם) והייצוא למסמך יישארו בתוך הפרק הזה בלבד, והוא יתווסף לרשימה כספר עצמאי משלו.

      מתקדם: הפניה מדויקת חופשית (לחלקים/פרקים מיוחדים שאינם ברשימה, כמו "Likutei Moharan, Part II 5")

        ייצוא ל-Google Docs

        פתיחת המסמך ↗ פתיחת הגיליון ↗

        הגדרות

        חיבור ל-Google Sheets/Docs

        1. ב-script.google.com צרו פרויקט חדש, מחקו את הקוד לדוגמה שכבר שם, ולחצו כדי להעתיק את הקוד שלנו והדביקו אותו:
          או צפו בקובץ ↗

        2. Deploy ← New deployment ← Web app. הגדירו Execute as: Me, Who has access: Anyone (לא Only myself - אחרת כל בקשה תיחסם ב-401, כי לדפדפן אין דרך להוכיח מיהו. הקוד עדיין רץ תמיד רק כמוכם, וכתובת ה-URL היא סוד שרק לכם יש)
        3. אשרו את מסך ההרשאות החד-פעמי (Sheets/Docs/Drive) ופרסמו
        4. הדביקו כאן את כתובת ה-URL שמסתיימת ב-/exec ולחצו שמירה, ואז בדיקת חיבור

        אין צורך לחבר גיליון או מסמך לכל ספר בנפרד - זו פעולה חד-פעמית וגלובלית. לכל ספר ייווצרו אוטומטית גיליון ומסמך משלו בפעם הראשונה שתשמרו או תייצאו עבורו פרשנות, והקישורים אליהם יופיעו במסך הקריאה של אותו ספר.

        לאחר החיבור, רשימת הספרים שלכם (כותרים, טווחים, והמקום שבו הפסקתם לקרוא בכל ספר) מתעדכנת אוטומטית לקובץ ב-Drive שלכם, כדי שתוכלו להמשיך מכל מכשיר. הפרשנות עצמה נשמרת מקומית ומוצפנת בכל מכשיר, אך גם נשלחת אוטומטית לגיליון של אותו ספר בכל שמירה - וכשפותחים ספר במכשיר אחר, הפרשנות שנכתבה במכשירים אחרים נמשכת חזרה מהגיליון ומופיעה גם שם.
